# SIGNAL 1.0.0

Initial Windows distribution release.

## Highlights

- Multi-source live news monitoring
- Regional presets and custom sources
- MANUAL / MULTI AUDIO / SCAN / NEWSROOM
- HEADLINES and rule-based BREAKING / ALERT signals
- Radio Monitor
- Japan Emergency Watch
- Cinema Mode
- Settings
- Ghostery-based CLEAN FEED
- Watchdog / Auto Recover
- Windows Installer and Portable builds
